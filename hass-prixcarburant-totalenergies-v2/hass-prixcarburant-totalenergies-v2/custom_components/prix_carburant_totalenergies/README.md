# TotalEnergies Prix Carburant V2

- Découverte automatique des stations dans un rayon configurable autour de la position Home Assistant.
- Sélection manuelle possible de stations.
- Prix Gazole/SP95/SP98/E10/E85/GPLc.
- Attribut `price_status: rupture` lorsqu'un prix est absent du flux instantané avec ruptures.
- Distance, coordonnées, adresse, ville, services et date du prix.
- Rafraîchissement configurable.

Installation HACS : ajouter le dépôt comme dépôt personnalisé de type Integration, installer puis redémarrer Home Assistant.
